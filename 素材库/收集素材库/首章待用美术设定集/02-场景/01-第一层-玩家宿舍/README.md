# 第1层：玩家宿舍

床、储物柜、工作台、水龙头和空杯在背景中留出位置，作为独立素材摆放。

- [00-预览](00-预览/)：背景和独立物件的拼装示意，包含角色与标注，只供查看。
- [01-固定背景](01-固定背景/)：2880×200 完整底图及九张 320×200 顺序分块。普通固定物件已画在背景中。
- [02-物品与家具](02-物品与家具/)：本层可单独使用的透明 PNG 和对应提示词。
- [03-动画](03-动画/)：本层动画帧、横向精灵图、GIF 预览和播放参数。
- [本层布局-素材示例.json](本层布局-素材示例.json)：预览所用的坐标与锚点，不是游戏程序配置。
- [本层素材清单.json](本层素材清单.json)：本层背景、独立 PNG 和动画规格。
- [00-参考](00-参考/)：保留本层已确认的完整设计参考图，包含已画死的物品；请勿与独立动画直接叠用。

## 动画

- [储物柜-开启](03-动画/储物柜-开启/)：储物柜开门，单次播放；关闭使用第 00 帧。
- [供水恢复-水滴](03-动画/供水恢复-水滴/)：仅在供水恢复时显示；停水状态保持干燥。

每组动画都有 4 张同尺寸透明 PNG、横向四帧 PNG 和动画信息。GIF 为便于查看而循环；实际是否循环以动画信息中的 loop 为准。播放开启类动画时，应把本动画第 00 帧用作关闭状态，而不是在另一张旧静态图和动画间切换。

## 使用边界

这是一套场景素材和摆放示例，本轮没有接入游戏。画在固定背景里的其他门、灯、货架等是静态图；尚无经过验证的独立开关门动画。背景里可能有外观类似的普通陈设，不要在同一坐标再次叠加独立物件。
