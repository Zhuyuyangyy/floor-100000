## 规格与检查

每层固定背景 2880×200，切为九张 320×200 PNG；每层的九块按顺序可逐像素还原本层完整背景，不能跨楼层混拼。五层使用相同画布和角色站位，已进行比例预览。所有动画提供透明 PNG 分帧、四帧横向图、GIF 预览和播放参数；开启动画的 GIF 为展示而循环，实际按各自的 JSON 判断是否循环。

普通固定设施已画在各层背景里，必要交互物件使用独立图片或动画，不要在背景里已有同款物件的位置重复叠加。旧版完整场景图包含已画死的物品，作为视觉参考使用。游戏接入、碰撞、遮挡及动画触发交由其他分支处理。
