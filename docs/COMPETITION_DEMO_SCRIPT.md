# 《第100000层：末日宿舍》竞赛演示视频脚本（草稿）

> 这是给**当前可验证首五层版本**的约 2–3 分钟剪辑提纲，不是已录制的视频。完整自动化生存旅程约需数分钟，包含较长的步行和等到可睡时间；若剪辑跳过等待/走路，应在画面或旁白中明确标注“剪辑跳转”。不要拼造未实际发生的 AI 输出、模型运行或游戏功能。

## 录制前准备

- 使用本地真实运行的当前提交；若要展示默认 NPC 行为，在未配置 `VITE_NPC_MODEL` 的默认模式下录屏，并让对话来源标签清楚可见。
- 主要旅程建议用桌面横屏录制，避免地图总览的手机竖屏未适配问题。可另加一段真实手机竖屏短镜头展示已测的首层触控，但不要暗示完整五层触控旅程已验证。
- 不要展示开发夹具、修改存档或伪造 AI 回答；如使用剪辑加速，标明跳切，不把它描述为一镜到底。

## 发布前核对

1. 将“试玩地址待公开部署后补上”替换为已经公开且实际打开验证的魔搭创空间链接；未部署前不要写成可试玩。
2. 将演示视频链接替换为真实上传、公开可访问的视频；画面要与最终提交版本一致。
3. 默认 NPC 标签和行为模式要在录制时重新确认；若切换到 Ollama，必须在视频中如实标出模型/本地服务，并保存可核验记录。
4. 不要称游戏已经完成 100000 层，不要暗示完整五层触控 E2E、真人试玩或现场模型推理已经通过。
