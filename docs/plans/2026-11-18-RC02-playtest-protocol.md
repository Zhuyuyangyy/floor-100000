# RC-02 人工试玩协议（给真人玩家）

- 目的：外部审查原话——「先真正玩一遍最新版本……证明新系统（每日目标/任务链/遭遇/NPC/成长/战斗反馈）真正解决了玩法问题」。机器 QA 验机制，此协议验**体验**。
- 版本：integrate/sprint-01-merge @ 当前 tip（跑前 `git log -1 --oneline` 记下 hash）
- 跑法：`npm run dev` → http://[::1]:5199/（vite 只绑 IPv6，localhost 会随机拒连；本机有代理的话浏览器关代理或 --no-proxy-server）

## 三个 seed 各一档，每档玩到第 3-4 天

seed 1 / seed 42 / seed 2026（开局时输入；同 seed 同结果，方便复现问题）

## 每档记录这张表（截图或笔记）

| 时间点 | 记录什么 |
|---|---|
| 开局 5 分钟 | 你是否清楚「我要干什么」？第一个目标是什么？（教程后） |
| 第 1 次背包满 | 什么时候满的？舍了什么留了什么？难不难割？ |
| 每层新发现 | 上了几层，每层遇到了什么新东西（资源/人物/危险/事件）？ |
| 每场战斗 | 打前怕不怕？打时有没有重量感（震屏/顿帧/闪光）？赢/残血的感受？ |
| 每晚入夜 | 二选一怎么选的、为什么？后果符合预期吗？ |
| 每天醒来 | 有没有「值得期待的下一天」？每日目标推你干什么？ |
| 物资曲线 | 什么时候开始紧？饿/渴/睡的真实压力出现在第几天？ |

## 六个体验问题（每档结尾各答一次，要具体例子）

1. 能迅速理解自己为什么要探索吗？
2. 每次上楼都能发现新的资源、人物或危险吗？
3. 背包满了会产生真正的取舍吗？
4. NPC 有自己的生活，而不是站着等玩家吗？（看它们走不走、记不记得你）
5. 战斗有重量感，胜利和失败都会影响后续生存吗？
6. 回到宿舍后，有值得期待的下一天吗？

## 必须核对的三个 M1 老问题（当年 B3-05 试玩结论的原话）

1. 「一天仍有 8 小时无事可做」——现在一天里你真正在做决定的时间占多少？纯赶路/纯等待有多少？
2. 「五层内容是一次性的，一次回取之后再无上楼理由」——下楼的理由现在是什么（每日目标？物资？好奇心？）？回取后再探索还有没有意义？
3. 内容重复感——第 3 层和第 7 层的「感觉」差别大吗？

## 劝退点优先

玩的过程中一旦出现「想关游戏」的瞬间，立刻记下：第几天、在做什么、为什么。这比任何评分都值钱。

## 报告格式（丢给总控即可）

每个 seed 一小节：上面各表+六问答案+三个老问题判定+「最爽的/最烦的/最想劝设计者的」各一条+劝退点清单。
