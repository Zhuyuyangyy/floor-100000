# M1 真人试玩协议：第100000层 · 末日宿舍

本轮只回答两个问题：新玩家能否独立完成五层生存循环，以及完成后是否还想继续。三份表格必须由三名真实试玩者填写；自动化 QA、开发者推测和历史记录不能代填。

## 开始前

- 仅使用通过 B3-19 集成门槛的本地候选版。记录确切 commit、构建命令、Node 版本和包的 SHA-256；CI/E2E 未通过时不得标为正式试玩候选。
- 试玩者 A 用 Seed 1，B 用 Seed 42，C 用 Seed 2026。每人使用独立浏览器配置/新建游戏，从第 1 层开始，不继承他人的存档。
- 允许 `?seed=1`、`?seed=42`、`?seed=2026` 固定随机数；禁止 `devfloor`、`devwin`、控制台改状态/时钟/物品/位置、修改存档、跳关或开发者代操作。
- 由观察者计时、记下原话和必要截图。征得试玩者同意后才录屏；不收集真实姓名等无关信息。
- 首轮观察 15 分钟；玩家愿意可再玩 15 分钟。若首次夜间或存档重载未覆盖，明确记为未验证，不靠改时间补齐。

## 给玩家的开场白

“你从塔楼第 1 层宿舍醒来。请像平常玩新游戏一样行动，试着活下去、探索，再回家。如果有什么想法可以说出来；不知道做什么也可以直接说。你可以随时停止。”

先不讲最佳路线、配方答案、掉落位置或该丢什么。操作提示应来自游戏本身。卡住约 60 秒时，可以问“你现在想做什么？”；若必须提示或救援，记录发生时间、原话及具体提示。救援后的步骤不能算独立完成。

## 怎么计时和记录

记录实际开始时间（带时区），再以可控制角色的第一帧为 `T+00:00`。下列时间一律记录为 `mm:ss`；未发生填“未发生”，不猜、不补零。

| 指标 | 统一定义 |
| --- | --- |
| 第一次操作 | 玩家第一次有意移动、交互或打开功能面板；不把标题页“开始”算作理解操作 |
| 第一次搜刮 | 玩家第一次通过真实交互从容器/地面获得物品；开局自带物品不算 |
| 第一次使用物品 | 第一次成功消耗物品并产生实际效果；满值被拒不算成功 |
| 第一次有意义的资源取舍 | 玩家能说出至少两个可行选择，并因背包、资源、风险或未来用途选择其一；记录放弃了什么及原因 |
| 第一次感到无聊 | 以玩家主动表述或追问后的回答为准；原地停留本身不代表无聊 |
| 困惑 | 记录时间、屏幕情境、玩家原话、尝试及是否自行解决 |
| 主动探索原因 | 不诱导；问“刚才为什么想去那里/再出去一次？”并记原话 |
| 是否愿意继续 | 结束时问“如果现在没人要求，你还想继续玩吗？为什么？”；填愿意/不愿意/不确定，并保留理由 |

观察重点：30 秒内理解开始/移动，3 分钟内找到资源并使用一种物品，第一日出现真正取舍，15 分钟后仍有主动目标。这些是观察标准，不应提前告诉玩家当作任务答案。

## 必须核对的真实操作覆盖

每项填写“独立完成 / 提示后完成 / 失败 / 未遇到”，附时间与证据。不得把另一个 seed 的情况填到本人的记录里。

| 项目 | 要看见的事实 |
| --- | --- |
| 第 1–5 层往返 | A/D 或方向键走到楼梯、E 触发；逐层上到 5 再下到 1；记录竖直/折返形态、角色是否消失/漂浮、镜头是否裁切 |
| 夜间宿舍行动 | 自然等到夜间，在床边打开安排并完成一个真实可支付的行动；记录资源和反馈 |
| 夜袭与战斗 | 分开记录宿舍夜袭的次日后果与问号点战斗；随机事件未出现填未遇到，不人为注入 |
| 行商和交易 | 走到行商或 NPC、打开面板，至少成功交换一次并核对钱/物品变化；失败交易不得半扣除 |
| 背包与资源 | 拾取、堆叠、满包反馈、使用物品；记录一次玩家自己的取舍 |
| 存档与重载 | 在游戏正常存档点退出/刷新，再通过“继续游戏”恢复；核对楼层、物品、已搜刮容器、夜间后果不重复也不丢失 |
| F 付费近路（独立检查） | 记录显示报价、实际扣费、跨层数与落点；钱不足应有提示且不扣款。不能把 F 跳层算作逐层楼梯覆盖 |

严重问题即时记录复现步骤；白屏、无法继续、存档损坏或不可恢复资源丢失时停止该次试玩，不指导玩家绕过后记为通过。随机事件三人均未遇到时列为覆盖空白，另安排后续自然流程补测。
