# 竞品逆向分析：CENTUM / ALTACIMA / The 100th Descent

**日期** 2026-10-29 · **目的** 回答“《第100000层》凭什么让玩家愿意玩下去”，为 B3 收尾与 B4 立项提供实证依据
**方法** leanrea 工作流。ALTACIMA 为付费游戏（NYP 被支付门槛挡住），取其公开页面全部设计信息；**CENTUM 为免费 HTML5，已下载完整源码（225,942 B，`re/centum/main.js`）逐行分析**；The 100th Descent 取公开页面。
**合规** 只做结构与数值分析，不取任何素材、代码、美术资源。

## 一、三款竞品的事实

### ALTACIMA（davideuggias，付费，最接近的玩法对标）

 itch 公开页全文（seen）：

- 100 层酒店生存 roguelike，**从阁楼向下**钻到 0 层出口（与我们向上爬镜像相反）
- **饥饿 + 精力**决定能走多远；每层一张小地图，问号点后藏敌人/赃物/商人/宝藏/叙事纸条（"new water" 的来历）
- **100 层程序化，每 10 层一个 Boss**；回合制战斗（攻击/格挡/逃跑）；可解锁角色；遗物与目标绑定
- 三档模式：快速跑 / 自动存档冒险 / 简单模式；全角色通关后开 post-game Basement
- **格子制移动**（手机点相邻格，PC WASD）

### CENTUM（aspacedog，免费 HTML5，本次深挖对象）

"100 层回合制 roguelike，找到 Zot 护符，从 100 层逃出"。完整源码已本地化，以下全部 seen（`re/centum/main.js`）：

**循环结构**

- 每层一张 8×8–12×12 cave 图（每格 30% 概率墙，重 roll 直到全连通），3 只怪，若干赃物
- **每 10 层（depth%10==0，100 层除外）= 商店层**：商人 + 神龛；护符层 = arena（全图无墙，1 件护符 + 满图怪）
- **停留升级机制（最重要）**：每层有 spawnRate=12–15 回合的计时器，归零时 roll：<10% 刷 0 只、<30% 刷 1 只、否则刷 2 只，难度 = 1+floor(总层数/10)。**在一层待得越久，来的怪越多越强**
- **付费跳层**：depth<47 或 59<depth≤90 且非护符层时，1–100+幸运 >70 生成捷径，depthAdd=2–4 层，价格 = 2×depth+90+已用次数×(25–35)。**跳层越用越贵**
- 宝箱怪每 16–30 回合潜伏刷新（treasureChestDelay）

**生存模型**

- 饱食 = **3 格“餐数”计数器**（不是连续衰减）：吃饭回 10% 最大 HP + 食物加成，饱着拒绝吃，0 格出 HUNGRY 状态（不掉血，但阻断食物回血）
- 食物三档：口粮（satiation 3 / 回血 3 / 50 金）、剩饭（3/8/80，带惩罚文案）、罐头（3/5/115）

**物品与怪物**

- 34 件物品：13 武器 / 8 护甲 / 5 遗物 / 3 食物 / 2 宝藏 / 1 卷轴 / 1 药水（卷轴药水走 spell roll）。每件带 **depth/maxDepth 窗口 + weight + basePrice**
- 武器带特殊攻击：sabre 双击（50%）、club 眩晕（50%）、高级武器力量加成
- 37 种怪，difficulty 1–9 阶梯 + 5 个特殊（99），**行为标签**：normal 23 / fast 5 / slow 4 / ranged 4 / nomove 2 / dig / greedy / charge / ignorewall 各 1
- 经验曲线：L2=80, L3=180, L4=280, L5=400, L6=550, L7=770, L8=900… 上限 L30；升级给属性点，另有 +1 物品槽 / +1 法术槽的一次性成长

**其他**

- 6 个手工教学关（movement / combat / items / gold / food+health / how to win），各 8×8 格
- 计分 = 2×深度 + 宝藏分 + floor(回合/3)×(胜利?1.5:1) + 胜利 1000——**深度绝对主导**
- 成就系统、localStorage 排行榜、exploration mode（不计分随便逛）

### The 100th Descent（chad301，免费 HTML5）

种子程序化楼层、永久死亡、回合制。"Ninety-nine went down. None came back."——同一公式的极简版，验证了“下行+种子+永久死亡”是可持续被复用的最小闭环。

## 二、对我们项目的借鉴（按价值排序，标注落点）

### 1. 停留升级机制 → 直接治“8 小时空窗”和“夜间零收益”（B3/B4）

CENTUM 的 spawnRate 计时器是本次分析最有价值的发现：**风险不来自夜晚，来自停留**。我们 M1_PLAYTEST 实测收工 12:00、空窗 8.0 小时；B3-06 实测夜里零收益、最优玩法是躲被子。

借鉴：楼层加“停留生成器”——每 N 游戏分钟 roll 一次事件（巡游体接近 / 异响 / 其他楼层动静），概率与强度随当层停留时长上升。空窗从“无事可做”变成“要么做事要么挨风险”，一夜之间同时缓解两个已实测问题。**不需要新系统，是 EventSystem 的一个计时器 + 权重表。**

### 2. 每 10 层一个锚点楼层（B4 生成器）

CENTUM 用商店层/护符层给 100 层打拍点；ALTACIMA 用 Boss/10。我们的六阶结构有梯度无节拍。B4 生成器直接内置：每 10 层 = 特殊层（商人 / 事件 / 强敌），普通层复用模板。**“下一层有东西”比“下一层还是走廊”更能支撑连玩两轮。**

### 3. 饱食=回复闸门（数值小改，张力大改）

我们饥渴是连续衰减曲线；CENTUM 证明“餐数计数器 + 吃饭回血 + 饱拒”更紧也更简单。可作为 B4 难度选项，或直接替换饥饿模型——**饱着不吃省食物，饿了才吃，每一次进食都是决策**。

### 4. 付费跳层 = 深度的货币化（B5 经济的第一块砖）

shortcut 的价格公式（2×depth+90+次数×30）把“层数”直接变成可计价资产。我们 B5 要的“同一物资多重价值”，跳层就是生存价值（省时间）与经济价值（花金币）的交汇点，且天然回答“取完回取之后再无上楼理由”。

### 5. 物品深度窗口（B4 内容梯度）

15 种物品 currently 无深度维度。抄 CENTUM 的 `depth/maxDepth/weight` 三件套：底层出布带/脏水，上层出稀有件，重量控制稀有度。**这是 B4“六大阶层资源梯度”的最小实现。**

### 6. 三个 30 秒教学关（P0-08 验收项）

CENTUM 用 6 个 8×8 手工关逐个教机制。我们 P0-08 要求“第一次玩无需外部文档”。做 3 个就够：移动+交互 / 吃喝+背包 / 上下楼。各 30 秒，可跳过。

### 7. 深度主导计分（回归理由）

score=2×depth 让“这次比上次深 3 层”成为可展示成就。我们加一个“历史最深楼层”持久化展示，成本一行，给玩家第二次打开游戏的理由。

## 三、明确不借鉴

- **cave 随机地图**（30% 墙 + 连通重 roll）：我们是横版走廊+房间，生成范式不同
- **回合制格子战斗**：我们是即时横版；只借“每次行动有代价”的思想（Terminus 同款），不借战斗形态
- CENTUM 的暗黑地城美术：我们的视觉语言走已定的 A+C 方向（清晰剪影 + 压抑氛围）

---

## 四、结论

三款竞品共同验证：**“爬/钻 + 生存资源 + 随机楼层”是成立的最小闭环，差异全在风险与奖励的编排**。CENTUM 源码级证据表明，抓住玩家的是四个可复用机制：停留升级的风险计时器、每 10 层的节拍锚点、深度计价的跳层经济、深度窗口的物品梯度。

对《第100000层》的直接结论：**不需要换引擎、不需要更多楼层，先借 #1（停留生成器）和 #6（教学关）——前者治已实测的 8 小时空窗，后者补 P0-08 未验收项。两者合计约一个小任务量，可进 B3 收尾或 B4 第一枪。**
