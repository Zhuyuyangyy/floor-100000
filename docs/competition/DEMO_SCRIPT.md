# 演示脚本（实机操作提纲）

> 录制当前工作版本的实际画面。脚本是操作提纲，不是已录制或已验证的演示；不改存档、不用 DevTools/控制台注入物品或信任、不拼接虚构结果。

## 约 1–2 分钟

1. **开始游戏**：从标题/开始界面进入一局正常游戏，展示实际 HUD 与当前楼层。
2. **取得维修材料**：正常走到第 2 层并打开维修材料箱；展示本局实际取得的木材×2、胶带×1。该配方由用户选定，材料箱保证可得。
3. **赠礼并提高信任**：走到阿林附近打开对话，选择赠礼，把净水逐个赠出三次；赠礼菜单应隐藏维修所需木材和胶带。所有库存、信任和记忆变化都应来自游戏内操作。
4. **维修门**：重新打开对话并选择“维修门计划”。在信任达到 70 且材料充足时，规则校验后的离线 fallback 执行动作；检查材料被消耗、门状态变为开放。
5. **验证进度变化**：关闭 NPC 对话，正常走到上行楼梯并按交互键，进入第 3 层。
6. **收尾**：停留在仍可继续游玩的游戏画面。该提纲尚未录制，不代表现场演示或公开发布已完成。
