## 六、译法约定

1. **人名音译**：阿林 = Alin、小周 = Xiao Zhou、周禾 = Zhou He（不本地化成本名）。
2. **塔内机构保留官僚感**：Hiring Desk / Access Control / Ruling Core 走「机构名」而非「人名」。
3. **玩家称呼**：NPC 对玩家不用 you know 之类填充，保持中文原文的短促（「别站着。」→ "Don't just stand there."）。
4. **文学性独白**允许更长的英文（`monologue.*`），窄屏 HUD 类文案必须短（`hud.*`/`nav.*`）。
5. **×、·、→、←/→** 等符号中英通用，不译。
6. 新增术语先补本表（含出处与语境），再进 `en-US.ts`；`i18n.test.ts` 会拦住未对齐的 key。
