# 美术交接规格 — 人物与动作

> 这份文档给你（美术）用。所有数字都来自当前代码，不是估计值。
> 你画完的 PNG **直接丢进 `src/assets/characters/` 就会自动覆盖**现有的 rig 产物，不需要改任何代码。

---

## 1. 文件与尺寸

四个角色，每个一张 PNG：

| 文件名 | 角色 |
| --- | --- |
| `src/assets/characters/player.png` | 幸存者（玩家） |
| `src/assets/characters/npc_alin.png` | 阿林（商店老板） |
| `src/assets/characters/npc_xiaozhou.png` | 小周（邻居小孩） |
| `src/assets/characters/wanderer.png` | 流浪者（夜间敌人） |

**每张图：1280 × 96 px**，横排 **20 帧**，每帧 **64 × 96 px**。

```
帧 0    帧 1    帧 2    ...  帧 19
┌────┐ ┌────┐ ┌────┐      ┌────┐
│64×96│ │64×96│ │64×96│ ... │64×96│
└────┘ └────┘ └────┘      └────┘
        1280 px 宽 × 96 px 高
```

8-bit RGBA，**透明像素的 RGB 必须为 0**（审计会查）。

## 2. 帧序（硬约定）

游戏按列号取帧，**顺序错了动作就会错乱**。

| 列 | 动作 | 帧数 | 帧率 | 时长 | 循环 |
| --- | --- | --- | --- | --- | --- |
| 0–5 | **行走** walk | 6 | 8 fps | 750 ms | 是 |
| 6–7 | **待机** idle | 2 | 2 fps | 1000 ms | 是 |
| 8–10 | **攻击** attack | 3 | 12 fps | 250 ms | 否 |
| 11–12 | **受击** hurt | 2 | 8 fps | 250 ms | 否 |
| 13–14 | **搜刮** search | 2 | 6 fps | 333 ms | 否 |
| 15–17 | **死亡** die | 3 | 6 fps | 500 ms | 否 |
| 18–19 | **拾取** pickup | 2 | 8 fps | 250 ms | 否 |

**行走是 6 帧一个完整循环**，第 6 帧要能接回第 1 帧（左右腿各完成一次摆动）。

## 3. 关键约束（违反会被审计打回）

### 3.1 朝右

所有角色**面朝右**。游戏用 `setFlipX` 处理向左，你不需要画镜像。

### 3.2 脚踩底线

每帧的**最低不透明行必须是 y=95**（也就是 96 高帧的最后一行）。

```
y=0   ┌──────────┐
      │          │
      │   角色    │   ← 头在这边
      │          │
y=95  └──────────┘   ← 脚底必须贴这一行
```

角色在场景里的锚点是 `(0.5, 1)`，即**每帧的水平中心、底部**。所以脚要落在帧的正下方附近，不要偏得靠左或靠右。

### 3.3 横向居中

角色的视觉中心应对齐帧的水平中心（x=32）。宽背包可以超出，但**重心别偏**。

### 3.4 调色板（16 色）

**只能用这 16 色**。审计会数颜色，超过 16 直接 FAIL。

```
中性（墙/地/UI/描边）
  #05080b  ink        最暗，描边与虚空
  #14202c  shadow     深影
  #2c3f4e  stone       墙基色
  #47657a  stoneLight  受光石面
  #8a95a0  dust        灰白 / 灰尘

布（幸存者外套）
  #1e4a44  clothDeep
  #2f6b5e  cloth
  #4e9c86  clothLight
  #77c6a4  clothHigh

皮肤
  #6b4630  skinDeep
  #a5714c  skin
  #d9b48f  skinLight

暖光（灯/火/金）
  #8a4a1e  lightDeep
  #d98b3c  light
  #f4b66a  lightHigh
```

> 这 16 色是**全项目共用**的，墙和地板也是这套。想加色必须先改 `src/render/palette.ts` 并重新审计，不要私自加。

### 3.5 亮度分离（最重要的一条）

墙的亮度是 **40.1**。

**角色身上落在 28–52 亮度区间的像素不能超过 25%**，否则角色会"溶"进墙里。当前 rig 版本是 18.5%，达标。

简单说：**角色整体要比墙亮一档**。深色只用在描边和小面积暗部，不要大面积铺 `#2c3f4e` 或 `#14202c`。

### 3.6 对比度

角色整体平均亮度与墙的差 **≥ 15**。当前是 44.7。

## 4. 四个角色的设计要点

| 角色 | 必须保留的识别特征 |
| --- | --- |
| **幸存者** | 青绿色连帽衫（`cloth` 系），**大帆布背包**：顶部一卷铺盖、中间一道压缩带和扣子 |
| **阿林** | 中年偏胖、**宽肩**、灰白短发和短须、钢蓝色工装背带裤（`stoneLight`/`stone` 系）、腰上挂工具 |
| **小周** | 约十二岁，**头大身窄**（这是唯一要点），琥珀色大外套长过臀部（`light`/`lightDeep` 系）、斜挎小包、短裤、运动鞋 |
| **流浪者** | **不是人**：约六头身、**窄**（最宽处约 37 px，幸存者约 52 px）、尖顶兜帽、**兜帽里没有脸**、手臂过长、身后拖一片破布。只用 5 个暗红黑色，是全项目最暗的角色 |

## 5. 每个动作怎么画

### 行走（6 帧，最关键）

一次完整循环 = 左右腿各走一步。6 帧分配：

| 帧 | 状态 |
| --- | --- |
| 0 | 左腿在前触地，右腿在后抬起 |
| 1 | 双腿交叉（过渡） |
| 2 | 右腿在前触地，左腿在后抬起 |
| 3 | 双腿交叉（过渡，与 1 镜像） |
| 4 | 回到帧 0 的姿态 |
| 5 | 与帧 1 相同（用于闭环） |

要求：
- **躯干高度有起伏**：双腿分开时身体高 2px，交叉时落下。这是走路"活着"的关键。
- **手臂反向摆动**：左腿前 → 右臂前。
- **背包跟着身体动**，但比躯干慢半拍（惯性）。
- 脚不要打滑 —— 着地的那只脚在两张图里应尽量停在原地。

### 待机（2 帧）

呼吸。帧 6 → 帧 7 → 回帧 6。躯干上下 1px，手臂微小摆动即可。**这是玩家看得最久的状态，值得画细。**

### 攻击（3 帧）

| 帧 | 状态 |
| --- | --- |
| 8 | 前摇：身体后仰，手臂收回 |
| 9 | 出手：身体前倾，手臂向前伸出 |
| 10 | 收招：回到接近待机 |

250 ms 内完成，**第 9 帧要最有冲击力**。

### 受击（2 帧）

| 帧 | 状态 |
| --- | --- |
| 11 | 后仰：头向后，身体反向弯，手臂张开 |
| 12 | 回弹一半 |

### 搜刮（2 帧）

弯腰翻容器。**躯干前倾、头低下、一只手向前伸**。第 14 帧比第 13 帧弯得更深。

### 死亡（3 帧）

| 帧 | 状态 |
| --- | --- |
| 15 | 踉跄：身体开始歪 |
| 16 | 倒下：躯干大幅旋转，膝盖弯 |
| 17 | 倒地：**停在最底的姿势**，游戏等这帧播完才切结算画面 |

500 ms，是全身动作，**要慢到看得清**。

### 拾取（2 帧）

站着、伸手向下捡东西。**不是弯腰翻容器**（那是搜刮）。帧 18 伸手，帧 19 拿到。

## 6. 道具（可选，同一个套路）

## 7. 交付后怎么验证

画完把 PNG 放进 `src/assets/characters/`，然后：

```bash
npx tsc --noEmit                              # 类型
npx vitest run                                # 570 单测
node tools/art-audit.mjs                      # 美术审计（五道门）
npx playwright test --workers=1               # 65 个 e2e
```

美术审计会报这几项，**全部 ok 才算过**：

```
character luminance 84.7 vs wall 40.1  ->  contrast 44.7     (≥15)
camouflage: 18.5% of the figure sits within 12 luminance      (≤25%)
PASS: readable=ok  dominant=ok  bright=ok  spread=ok  density=ok
```

浏览器里看实际效果：`npm run dev` 打开 http://localhost:5173/?seed=42
