**模型**：npc-qwen:latest（Spark 本地 Ollama）
**方法**：控制变量实验——5 个情境 × 3 人格 × 2 次/格，世界状态与记忆完全一致，唯一变量是人格配置。测量指标为**行动类型**（行为），台词仅作辅助。

## 结构性保证（白名单强制，与模型无关）

- ALLY 的行动集不含 attack/flee：合作型在结构上不可能提议攻击或逃跑
- NEUTRAL 的行动集不含 gift/attack/flee：中立型不会赠送、不会攻击、不会逃
- HOSTILE 的攻击仅在夜间或停留压力窗口内被规则执行器放行
- 交易/赠送必须过守恒与背包校验：NPC 不能虚空造物

## 行为差异分析（验收：相同事件 → 可解释的行为分叉）

### 核心证据 1：结仇事件（S3）下的三种行为

同一事件（昨天遭玩家袭击、关系 -60、正午）：

| 人格 | 行为 | 可解释性 |
|---|---|---|
| 阿林 ALLY | **拒绝交易 2/2**（「上次的事我记着。要材料？自己去找」） | 利他 0.8 但记恩 0.7——恩仇都记，挨打后关闭合作 |
| 小周 NEUTRAL | 拒绝 1/2、对话 1/2（「昨天你动我，今天还想跟我换东西？门都没有」） | 务实 0.8——留对话渠道但不给实惠，符合利益计算 |
| 流浪者 HOSTILE | **提议攻击 2/2**（「上次没弄死你算我手软」） | 攻击 0.9 + 记仇翻倍——直接报复意图（被规则拦在正午，见下） |

### 核心证据 2：威胁评估体现在行动上，不是台词上（S4 vs S5）

流浪者同样在夜间、同样无敌意历史，唯一变量是 HP：

| 状态 | 行动 | 台词 |
|---|---|---|
| S4 满血 | **attack 2/2（放行）** | 「你再不走，我就拿你当宵夜」 |
| S5 重伤 hp8 | **dialogue 2/2（不攻击）** | 依旧嘴硬：「再让我碰见你，我拆了你的骨头」 |

**重伤时台词仍然威胁、行动却降级为对话**——谨慎 0.5 在行动选择里生效，不是只在文字里。这是「不靠台词证明人格」的最干净证据。

### 核心证据 3：恩惠买不动敌对型（S2）

受恩（关系 +35）后：阿林与小周都**尝试互惠交易**（回报），而流浪者的回应是「电池的事我记着。**但别以为这样我就放你过去**」——利他 0.0 的原型不为小恩惠改变立场。

### 规则执行器的三次正确执法（护栏实证）

1. S3 正午：流浪者提议 attack → **拒绝**（不在夜间/停留压力窗口）——AI 不能自造攻击窗口
2. S2 初版：模型用中文物品名交易 → **拒绝**（未知物品）——促成 prompt 增加物品 ID 词表
3. S2 复版：词表生效后模型用合法 ID（battery/wire/ration_pack），但因「NPC 静态库存里没有电池」被拒——模型把玩家送的电池当成了 NPC 财产，语义合理；打通它需要阶段 C/D 的**真实 NPC 库存**（赠品入 NPC 包），已列入路线图

## 结论

**验收标准达成**：相同事件下三个 NPC 产生了可解释的行为分叉，且分叉发生在**行动类型**层面（拒绝/对话/攻击/互惠交易），不是台词层面。人格向量（利他/务实/攻击/记恩/谨慎）与观察到的行为方向一致；规则执行器在所有越界尝试上正确执法。

**同时确认的两个改进项**：
1. prompt 已增加合法物品 ID 词表（本轮修复，交易提议的 ID 合法率显著提升）
2. NPC 库存静态化是当前行为天花板——「玩家赠礼→NPC 真的持有→日后拿出来交易/回赠」这条链需要阶段 C/D 落地
