# B3-08 — 场景尺度归一：家具降到 56px，门与窗重画

- 里程碑：M1 可玩原型
- 日期：2026-10-28
- 分支：`feat/tower-zoom-b2`
- 上游：[`B3-07_CHARACTERS.md`](B3-07_CHARACTERS.md) §5 选项 A
- 目标：把场景里三套互不相关的尺度（16px 瓦片 / 48px 角色 / 80px 家具）收敛到两套，并让门与窗回到建筑尺度

---

## 1. 先立测试，再动手

新增 [`src/tests/sceneScale.test.ts`](../src/tests/sceneScale.test.ts)，9 条不变量。关键是**用比例而不是绝对值**——这样整套素材可以等比缩放而不用改测试：

| 不变量 | 阈值 | 改前实测 |
|---|---|---|
| 四个角色同一画布（脚底基线规则） | 高度全等 | ✅ 48 |
| 所有道具同一站立高度（免得像贴纸） | 高度唯一 | ✅ 80 |
| **道具不能比人高太多** | ≤ 1.25× 人 | ❌ **1.667**（80 vs 48） |
| 道具也不能小到像渣子 | ≥ 0.9× 人 | ✅ 1.667 |
| **门不能比人矮** | ≥ 人高 | ❌ **16 vs 48** |
| 窗要大到像窗 | ≥ 0.75× 人 | ❌ **0.333** |
| 门要窄于高 | 宽 < 高 | ❌ 16 = 16 |

四条 RED 的失败信息直接就是我实测过的数字（`tallest prop 80px vs player 48px`、`door is 16px, player is 48px`），不是笔误。

为此把 `textureKeys.test.ts` 里那个录制 stub 提成共享的 [`src/tests/bakeProbe.ts`](../src/tests/bakeProbe.ts)，让它除了贴图键还吐出宽高——否则瓦片尺寸只存在于 `bake()` 的字面参数里，测试读不到。

## 2. 改了什么

### 家具 80 → 56

`tools/build-artpack.mjs` 的 `FURNITURE_HEIGHT` 改 56，重跑。九件道具现在全是 56px 高，宽度按各自长宽比：

| 道具 | 原尺寸 | 新尺寸 |
|---|---|---|
| bed | 210×125 | 94×**56** |
| cabinet | 164×228 | 40×**56** |
| crate_wood | 140×132 | 59×**56** |
| crate_metal | 141×120 | 66×**56** |
| workbench | 244×164 | 83×**56** |
| watertank | 158×175 | 51×**56** |
| fusebox | 154×168 | 51×**56** |
| shelf | 138×155 | 50×**56** |
| counter | 222×114 | 109×**56** |

**`corridors.ts` 的坐标一个都没改。** 这点值得单独说，因为 B3-07 报告 §5 说错了：所有道具都是 `setOrigin(0.5, 1)` 底锚定，贴图变矮只是向上收；容器标签用 `box.displayHeight` 自动跟随；货箱堆叠间距读的是贴图实际高度。所谓「五处按 80px 调好的写死坐标」不存在——已在该报告里更正。

真正要改的是**门变高带来的两处新冲突**：

| 位置 | 问题 | 修法 |
|---|---|---|
| 第 2 层门牌 `floorY - 36` | 门长到 56px 后，门牌印在门身上 | 移到 `floorY - 66`（门高 + 间距，不再写死 36） |
| 宿舍门底边 `wallH - 16` | 16px 门那道 16px 缝看不出来，56px 门就像浮着 | 改踩地线 `wallH`，仍在 48px 地面带之外，不挡走道 |

### 门 16×16 → 24×56，窗 16×16 → 32×40

`src/render/pixelArt.ts` 重画两个抽屉：

- **门**：外框 + 门板 + 上下两块镶板（带镶板缝和投影）+ 把手 + 两侧板缝
- **窗**：外框 + 夜玻璃 + 天花带 + 远处一亮窗 + 微弱反光 + 十字窗棂 + 窗台

## 4. 还剩一套尺度没解决

**墙和地还是 16×16 程序化瓦片。** 这是三套尺度里最后一套，也正是你最早指的「小格子和贴图格格不入」。它没法用改常数解决——`arch/` 那 62 块全是 41–235px 的单件道具，没有一块可平铺的墙或地，所以必须你提供或生成背景。规格在早前消息里给过（1280×360 整幅、不要瓦片、色板、受光方向、y=232–312 别放关键细节）。

在背景到位之前，场景是「大尺度道具 + 大尺度门 + 48px 人 + 16px 砖墙」——比原来的三套冲突好很多，但砖墙的格子感仍在。
