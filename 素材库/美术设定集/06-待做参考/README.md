## 命名规则

`阶段-主体-类型.png`，例：

```
B4-区段总览-参考.png
B9-贫民区走廊-气氛参考.png
怪物-巡游体-设定图.png
```

前面带阶段号（对应 `docs/ROADMAP.md` 的 B4/B5/B9），是为了以后有人接手时，一眼知道这张图是给哪个阶段用的。

## 收图的标准

一张参考图值得放进来，至少要能回答一个问题：

- **形**：这个东西长什么样，轮廓和比例
- **色**：在这个世界里是什么颜色倾向
- **用**：玩家在什么场景下会看到它

只回答"感觉不错"的图，放进来会让后面的人更困惑。宁可少放。

参考图不等于可以抄的图。**任何第三方作品的截图、原画、素材，只能作为风格参考，不能切片进游戏。**
