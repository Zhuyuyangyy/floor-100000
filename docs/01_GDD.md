# GDD — 第100000层：末日宿舍

状态：产品设计基线 v0.1（暂定规则，可通过设计变更审议）。

## 1. 一句话卖点

在一栋看不见底的十万层末日宿舍楼里，你从第 100000 层的一张床开始，靠探索楼层、与邻居互助或交易、搜集与制作资源，熬过 7 天。真正的敌人不只是怪物，还有缺水、停电和人与人之间的选择。

## 2. 设计支柱（优先级按顺序）

1. **真实可玩**：角色可移动、物品可使用、数值会变化、选择有后果。
2. **宿舍生存感**：从逼仄的小房间逐步改造安全屋，安全感随资源积累提升。
3. **垂直楼层探索**：上楼/下楼各有风险；用楼层编号和程序化生成营造规模感。
4. **邻居社会**：可信的交易、求助、资源冲突；首版不做云端 LLM 对话。
5. **能产生故事**：一次停电、一次被骗、一桶脏水就能改变玩家当天的行动。

## 3. 世界观

公元 2089 年，地表被黑雾覆盖，人类迁入一栋超巨型宿舍塔。你醒来时住在第 100000 层，广播宣布停电、运力瘫痪，食物和净水供应中断。你有一张床、一个柜子、3 瓶净水、2 份口粮、一支低电量手电。没有外部救援能立刻到达。

**美术故事不是现成网络视频改编**：仅借鉴“巨型宿舍/高层生存”这一抽象题材，必须创作原创人物与情节。

## 4. 首版的镜头、空间与输入

- **2D 横版剖面**，镜头主要跟随主角；一层内可左右行走，楼梯/出口靠近按 E 切楼层，不需要跳跃或平台动作。
- 每层由 4 个固定宽度的房间模块拼接（宿舍、走廊、仓储、设施等），使用 16px tile 像素风。
- 首版只允许探索 100000、99999、99998、99997、99996 共 5 层。延伸版本目标 20 层；整栋楼可通过种子与楼层号后续按需生成。
- 操作：A/D 或左右方向键移动；E 交互；I 背包；C 制作；M 楼层概览；ESC 暂停。交互距离有限，显示提示。不要求鼠标点击才能生存。

## 5. 主循环（每一天）

```
宿舍醒来 -> 查看补给与状态 -> 选择目标楼层
     -> 探索/拾取/交换/修理/躲避风险
     -> 天黑前回宿舍 -> 使用/制作物品 -> 睡觉过天
     -> 触发新一天事件 -> 重复，直至胜利或死亡
```

- 正式胜利：在第 7 夜结束后到达第 8 天 06:00，且生命值仍大于 0。
- 失败：生命值降至 0。展示死因与存活天数，可从新档重开。
- 无软锁：需要的关键资源必须存在至少一个确定性获取路径，不可让玩家因随机数完全无法推进。
- 活一昼夜不只是等待：需要有至少 3 次有意义的行动（拾取、交易、制作、睡觉等）。

## 6. 生存数值（初版建议值，最终以 config/game-balance.json 为准）

| 指标 | 初值 | 变化逻辑 |
| --- | ---: | --- |
| HP 生命 | 100 | 受伤或极度饥渴下降；医疗包恢复 |
| 饥饿 | 80 | 每游戏小时下降 2；食物恢复 |
| 口渴 | 80 | 每游戏小时下降 3；水恢复 |
| 精力 | 80 | 每游戏小时下降 3；睡眠恢复 |
| 背包 | 12 格 | 同种物品可堆叠，满了就不能拾取 |

真实 1 秒 = 游戏内 3 分钟；从早晨 06:00 出发，到 20:00 允许回床睡觉；此后走廊风险提高。上述数值都是需要 playtest 后调优的起始参数，不是不可修改的真理。

## 7. 五层固定布局（首版）

| 楼层 | 场景 | 核心功能 |
| --- | --- | --- |
| 100000 | 玩家宿舍 + 公共走廊 | 初始床铺、储物、制作、睡眠、安全屋 |
| 99999 | 邻居宿舍 | 2 名可交易的 NPC、简短对话 |
| 99998 | 废弃储物层 | 搜集木材、金属、胶带、电池；有消耗性容器 |
| 99997 | 维修层 | 漆黑区域、稳定可找到的保险丝、设施资源 |
| 99996 | 废弃食堂 | 食物补给、强化风险、首版探索终点提示 |

首版每层可以用固定布局/确定性参数化布局，不要求真正复杂的随机生成。以后延伸到 20 层时增加楼层模板与地图变化。不要为“十万层”预加载或预渲染海量地图。

## 8. 道具与制作（首版）

物品：净水、脏水、压缩口粮、面包、电池、废金属、木材、布料、胶带、滤芯、电线、医疗包、撬棍、保险丝、手电，共 15 种。材料必须有具体的获得方式，不能出现菜单能制作但全图找不到的配方材料。

制作台（在宿舍内使用）：
- **照明灯**：电池 1 + 电线 1 + 废金属 1；宿舍夜间照亮，不再依赖手电维持基础光照。
- **加固门**：木材 2 + 胶带 1；降低夜间随机威胁进入宿舍的概率。
- **简易净水器**：废金属 2 + 滤芯 1 + 电线 1；建成后可把脏水转换为净水，仍需耗时/冷却。

在 MVP 中道具只实现清晰可见的效果，不用造复杂的科技树。

## 9. NPC（不接大模型 API）

- **阿林（维修工）**：掌握电线/保险丝信息，偏好电池和废金属，能进行材料交换。
- **小周（邻居）**：提供食物与水交换，行为偏务实，可能提出一次简单求助。

NPC 状态机：闲逛/待机/交易/回房。对话采用选项树：问候、询问、交易、退出；至少两个选项能实际改变背包与资源。必须能通过键盘完成对话。

## 10. 风险事件

- **走廊停电**：需要手电或安全返回；屏幕不能直接全黑到不可操作。
- **夜间巡游体**：一类简单的追逐威胁，触发后可躲回房间或通过换楼层逃离；首版不强制战斗。
- **漏水/物资紧缺**：改变一个区域的物资或行动成本，不应导致无解局面。
- 每游戏日至多一个主要随机事件，由 seed 决定，并向玩家清楚提示。

## 11. 非目标（首版严格排除）

多人联机、排行榜、账户登录、商城/付费、AI 自由聊天 NPC、3D、复杂物理、动作战斗、无限技能树、数百种材料、移动端虚拟摇杆、云存档、十万层同时加载、超长剧情、新手教学大系统。

## 12. 扩展阶段：v0.2 / v1.0

- **v0.2**：扩展到 20 层、8 名 NPC、楼层模板、更多随机事件、初步剧情分支。
- **v1.0 候选**：垂直聚落、派系声望、不同生存策略、玩家日志/事件回放。以上需要验证 v0.1 有趣后再立项。

## 13. 核心体验验收

第一次打开玩家在 30 秒内能理解移动与交互；3 分钟内完成拾取/使用；第一天有一个明确选择；玩家能实际在 7 天内取胜，不能靠手动篡改存档；死亡后能知道原因。
