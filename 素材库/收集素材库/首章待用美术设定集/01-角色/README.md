之前生成的其他楼层角色草稿集中在「90-后续楼层草稿」，每人各有文件夹。

## 角色视角与动作素材

每位角色均有正面、背面和右侧面参考，另有动作原画、按动作分类的 64×96 PNG 单帧、GIF 对齐预览以及 1280×96 的 20 帧游戏导入候选表。每位角色目录中的「素材说明.md」列出对应文件。

游戏表从第 0 帧开始依次为：行走 0–5、待机 6–7、攻击 8–10、受伤 11–12、搜索 13–14、倒下 15–17、拾取 18–19。角色表已在独立 Phaser 页面按 64×96 成功加载，七种 GIF 的帧数和尺寸已检查。隔离构建通过资源替换方式成功加载了幸存者、阿林、小周、巡游体四张候选表；四位角色的待机、向左及向右行走已在游戏场景中检查。在隔离构建中，四位角色的搜索、攻击、受伤、拾取和倒下动作也通过游戏逻辑入口检查；这些验证使用了测试状态和方法调用，并非完整剧情流程的人手验收。贴地适配属于隔离验证的候选实现，尚未作为本次素材交付接入主线；周禾也尚未接入游戏。

行走原画与角色表朝右。隔离验证中玩家角色和巡游体敌人向左移动时水平镜像同一组帧，因此左侧朝向的饰品位置也会随之镜像；素材库没有单独绘制的向左 GIF。周禾尚未接入当前游戏。
