# 《第100000层：末日宿舍》首章世界与玩法设计规范 v0.1

**状态**：已确认的首章设计基线  
**日期**：2026-11-11  
**适用里程碑**：M1 收尾 → 真人试玩 → B4/B5 扩展准备  
**关联权威文档**：[`GAME_DESIGN_LOCK.md`](../GAME_DESIGN_LOCK.md)、[`ROADMAP.md`](../ROADMAP.md)

## 1. 设计目标

首章要验证的不是“能否做出五张更大的地图”，而是能否形成一条可重复、可扩展、具有生存压力的长期循环：

```text
固定主基地准备
  → 携带有限补给进入新楼层
  → 搜索 / 交易 / 观察 / 战斗 / 选择深入程度
  → 带着材料回家或退到临时据点
  → 储存 / 制作 / 修理 / 治疗 / 防御
  → shelter 决策与睡眠结算
  → 新一天获得新的路线、材料用途和楼层动机
```

首章必须让玩家明确感受到：家值得保护，材料值得带回，楼层具有不同身份，武器和工具会改变可走的路线，观察世界会产生后果。

首章不追求十万层的手工内容，而是制作一个能够复制到更高阶层的正确样板。

## 2. 三层世界架构

### 2.1 作者设计层

用于主基地、章节关键楼层、特殊居民、门禁、守门人、壁画与关键事件。作者内容承担叙事、情感和独特规则，不追求数量。

首章作者内容包括第 1–5 层、固定主基地、三处关键 Inspectable、一个楼层门禁链和第五层守门人。

### 2.2 规则生成层

用于 B4 之后的普通楼层。由楼层阶层、资源梯度、危险模板、居民生态和种子生成可复现地图。生成楼层必须共享首章的资源价值、通行条件和生存规则，不能只换贴图。

### 2.3 动态社会层

用于后续 NPC 记忆、关系、交易、迁移、派系和冲突。首章只保留接口与少量固定居民，不在本轮实现完整 AI 社会模拟。

## 3. 固定主基地与高层临时据点

### 3.1 第 1 层固定主基地

第 1 层是玩家唯一的长期家，不能被普通失败轻易摧毁。基地功能逐步开放：

| 功能 | 首章作用 |
|---|---|
| 床位 | 睡眠、次日恢复、压力结算 |
| 储物柜 | 跨日保存资源，缓解远征背包压力 |
| 简易工作台 | 制作基础工具、武器、修理品 |
| 净水设备 | 将脏水转为稳定饮水来源 |
| 防御设施 | 降低夜袭和宿舍风险 |
| 居民交互点 | 承载照顾、交易、委托和关系记忆 |

基地升级必须消耗远征带回的材料，并让下一次出发更安全或更有选择，而不是只增加数值。

### 3.2 高层临时据点

临时据点是远征支点，不是第二套基地系统。首章只提供：

- 临时储物。
- 临时休息。
- 简单治疗或补水。

临时据点不能替代第 1 层的高级工作台、长期仓库、完整防御和关系中心。它的价值是减少长距离往返带来的纯时间成本，同时保留“回家处理后果”的意义。

## 4. 首章地图与七天节奏

### 4.1 地图身份

| 楼层 | 身份 | 核心资源 | 独特规则 | 关键记忆点 |
|---|---|---|---|---|
| 第 1 层 | 固定主基地：贫民宿舍 | 储物、脏水、基础食物 | shelter、夜袭、制作 | 玩家自己的床、门和工作台 |
| 第 2 层 | 废弃居住层 | 食物、脏水、布料、废料 | 配给紧张、住户冲突、低照明 | 饮水配给、住户照片、留言墙 |
| 第 3 层 | 维修工业层 | 废金属、电线、电池、工具零件 | 漏电、机械敌人、噪音路线 | 工人壁画、维修通道、断电控制台 |
| 第 4 层 | 诊疗能源层 | 药品、滤芯、燃料、高级材料 | 寒冷、停电、感染风险 | 医疗记录、儿童画、能源真相 |
| 第 5 层 | 门禁与章节挑战 | 通行资格、章节奖励 | 守门人、资源检查、路线选择 | 守门人和背后组织 |

第 2–4 层是三张作者设计地图，第 5 层是章节收束。每张地图必须同时拥有独特资源理由、独特危险、独特地标和至少两处可观察内容。

### 4.2 七天节奏

七天是首章节奏目标，不是强制倒计时。熟练玩家可以提前获得第五层资格，慢节奏玩家可以继续发展；第七天提供阶段性生存检查与更强的夜间压力。

| 天数 | 主要目标 | 典型产出 |
|---|---|---|
| 第 1 天 | 认识基地，建立基础生存能力 | 储物、净水、简易工作台材料 |
| 第 2 天 | 探索第 2 层并稳定饮水与食物 | 布料、脏水、住户线索 |
| 第 3 天 | 修复第 3 层通路 | 电线、废金属、第一件正式武器 |
| 第 4 天 | 强化基地和临时据点 | 强化工作台、修门、临时储物 |
| 第 5 天 | 进入第 4 层寻找医疗与能源 | 药品、滤芯、电池、停电线索 |
| 第 6 天 | 处理门禁条件和关系选择 | 通行资格、备用路线、章节准备 |
| 第 7 天 | 挑战第五层或完成阶段性生存目标 | 守门人结果、章节日记、下一章动机 |

## 5. 解锁链与多路线原则

楼层解锁使用世界内可解释的条件，不使用经验等级或无理由传送：

1. 第 2 层：从第 1 层自然楼梯进入。
2. 第 3 层：找到保险丝并修复维修通路。
3. 第 4 层：修复电力节点，或通过居民/工人获得通行资格。
4. 第 5 层：完成诊疗能源层的关键任务，获得门禁权限。

关键装备不应成为唯一钥匙。撬棍、电击器和短剑可以提供更安全或更短的路线，但每个关键区域至少保留一条替代路径，例如绕路、交易、维修、潜行或承担更高风险。

## 6. 材料多用途矩阵

首章先控制在八类核心材料，稀缺性主要来自用途冲突，而不是单纯降低掉落率。

| 材料 | 生存价值 | 制作价值 | 任务 / 通行 / 交易价值 |
|---|---|---|---|
| 食物 | 恢复饥饿 | 简易口粮 | 照顾居民、交易 |
| 脏水 | 净水原料 | 净水设备 | 交易、配给任务 |
| 废金属 | 修理设施 | 武器、工作台 | 修门、交换通行 |
| 电线 | 维修设备 | 工作台、照明 | 修复楼层通路 |
| 布料 | 保暖、包扎 | 医疗包、护具 | 交易、居民任务 |
| 电池 | 临时照明 | 电击器、供电设备 | 门禁、能源节点 |
| 药品 | 治疗伤病 | 高级医疗包 | 医疗居民任务、换资格 |
| 滤芯 | 净水 | 高级净水设备 | 第 4–5 层通行条件 |

示例决策：玩家只有三个电池时，可以制作照明、修复门禁，或交给居民换取资格；系统应让三种选择都合理，而不是设计唯一正确答案。

## 7. 工作台与武器成长

### 7.1 工作台

| 等级 | 获得方式 | 首章配方范围 |
|---|---|---|
| 简易工作台 | 第 1 层使用废金属 + 电线建成 | 木棍、简易刀、火把、修理包、绷带 |
| 强化工作台 | 从第 3 层带回工具零件后升级 | 撬棍、短矛、电池灯、护具、加固门组件 |
| 供电工作台 | 第 4 层取得电池与滤芯后解锁 | 电击器、短剑、高级医疗包、门禁设备 |

首章可以先完整实现前两档，第三档作为第 4 层之后的明确成长目标；不能因为第三档尚未实现而阻断前两天的可玩循环。

### 7.2 武器与工具

武器成长改变路线和风险，而不只是增加攻击力：

| 装备 | 主要作用 | 替代方案 |
|---|---|---|
| 木棍 | 低成本基础防身 | 逃跑、躲避 |
| 简易刀 | 第 2 层基础战斗 | 交易或绕路 |
| 撬棍 | 打开维修门和障碍 | 找备用入口 |
| 短矛 | 拉开距离，降低近战风险 | 火把照明后快速通过 |
| 电击器 | 对机械敌人和门禁有效 | 修理、断电、绕行 |
| 短剑 | 第 5 层战斗准备 | 交易资格或承担更高消耗 |

## 8. Inspectable 与世界叙事

墙画、照片、留言、医疗记录和居民物品统一进入 `Inspectable` 数据结构。观察内容必须产生游戏反馈，至少满足以下一种：

- 写入事件日记。
- 标记隐藏路线或资源点。
- 解锁居民身份与关系线索。
- 改变当天目标或下一次遭遇的文本。
- 提供交易、通行或派系判断依据。

首章示例：

- 第 2 层住户照片：标记饮水配给负责人。
- 第 3 层工人壁画：揭示维修通道和旧工会符号。
- 第 4 层医疗记录：揭示感染与停电的关联。

Inspectable 不直接大量发放资源，避免退化为“点击墙画领奖励”。

## 9. NPC 与后续社会系统接口

首章的居民先作为固定角色和明确需求存在：

- 第 2 层：控制饮水配给的住户。
- 第 3 层：掌握维修技术的工人。
- 第 4 层：掌握药品与感染信息的医生。
- 第 5 层：守门人及其背后的组织。

本轮不实现完整自主社会模拟，但数据结构要允许保存身份、需求、信任、记忆和所在楼层。玩家的物品可以同时影响生存、交易和关系。

## 10. 现有系统复用映射

| 新设计 | 现有系统 / 资产 | 处理原则 |
|---|---|---|
| 生存、时间、睡眠 | `SurvivalSystem`、现有 shelter 流程 | 复用，不重写时间规则 |
| 搜刮与容器 | `LootSystem` | 扩展楼层资源表，保留确定性获取路径 |
| 制作与净水 | `CraftingSystem` | 先扩配方，再考虑工作台等级门槛 |
| 战斗 | 现有回合制战斗 | 武器改变选项和反馈，不改纯逻辑边界 |
| 自然楼梯 | B3-19 楼梯实现 | 解锁改变可通行条件，不恢复传送式切层 |
| 交易 | `TradeSystem` | 让材料兼具经济和关系价值 |
| 事件日记与压力 | B3-17/B3-18 设计 | 作为跨天后果和世界记忆入口 |
| 像素特效 | `src/render/fx.ts` 与 pixelfx 图集 | 只接入服务战斗反馈的必要效果 |
| 现有美术资产 | 家具、角色、刀剑、特效 | 优先用于地标、工作台、武器和反馈，保持许可记录 |

## 11. 验收标准

首章设计不以文档完整为验收，而以可玩证据为准：

1. 新玩家能理解第 1 层是家，能储存、制作、睡眠和修理。
2. 第 2、3、4 层至少各有一个独特规则、一个独特地标、一种独特资源理由和两处可观察内容。
3. 玩家能在 3–7 天内完成“准备 → 远征 → 带资源回家 → 制作/修理 → 睡眠 → 新动机”的至少两轮循环。
4. 同一材料至少存在两种合理用途；测试不能只验证掉落数量，还要验证用途冲突。
5. 没有关键装备时，至少存在一条代价更高的替代路线，避免软锁。
6. 观察墙画、照片或记录后，日记、地图、目标、关系或路线至少有一项变化。
7. 临时据点能减少无意义往返，但不能替代主基地的长期升级。
8. 首章完成后，玩家能说出下一次出门的明确理由，而不是只剩“继续搜空箱子”。
9. 所有关键状态持久化：已探索、已读 Inspectable、通路修复、工作台等级、武器、基地设施和 NPC 关系。
10. 现有 `GAME_DESIGN_LOCK.md` 的起点、向上攀升、自然楼梯和长期社会目标不被破坏。

## 12. 开发边界与顺序

正式开发顺序：

1. 完成 B3-19 / M1 收尾与真人试玩，先验证现有基础循环。
2. 用首章设计修正 B3 的资源动机和回家价值，不立刻铺十万层。
3. 先实现第 1 层基地升级、第 2–4 层身份化地图、材料用途矩阵和工作台前两档。
4. 再接第 5 层门禁与章节挑战。
5. 通过真人试玩后，才进入 B4 的程序化区段与 B5 的经济/基地扩展。
6. NPC 自主行为、派系迁移和十万层动态生态作为后续阶段，不阻塞首章可玩性。

本规范不要求一次实现全部配方、全部居民行为或全部终局。它的职责是把首章做成可玩、可验证、可复制的世界样板。
