# HUD 概念图接入说明（2026-11-14）

本目录是 `F:/new/末日宿舍_HUD_UI分件包.zip` 的原始解包，**只作设计参考，不是运行时资源**。
包内 README 已说明：这些是从概念图直接裁切的 RGB PNG，背景不透明、数字是画上去的
（生命 100 / 饥饿 65 / 口渴 64 / 精力 79 / 金币 0 / 分数 2066），整条 HUD 宽 1656px，
而游戏设计画布是 1280×720。

## 为什么没有直接贴图

| 概念图的情况 | 直接贴图的后果 |
|---|---|
| 背景不透明 | 盖住背后的游戏世界（现在的 HUD 是半透明板） |
| 数字画在图上 | 数值永远是概念值，不会随游戏变化 |
| 1656px 宽 | 缩到 1280 要走 `pixelArt:true` 的最近邻重采样，金属细节全糊 |
| 每个模块独立裁切 | 模块间距按 1656 画布排的，1280 上放不下 |

## 落地方式

按这张概念图**重画**了一套运行时 HUD：`src/render/hudSkin.ts`（铆钉板、斜纹警示条、
13 个 8×8 像素图标）+ `src/scenes/GameScene.ts` 的 `buildHud()`。

| 概念图元素 | 代码里的样子 |
|---|---|
| 顶部整块铆钉板 + 左侧暖色竖条 | `drawHudPlate()`，板高 132px |
| 第1000层 / D1 06:12 | 左侧塔楼 + 日历图标，20px 楼层号 + 12px 时钟 |
| 生命/饥饿/口渴/精力 四组 | 图标 + 标签 + 右对齐数字 + **10 段** 10px 状态条 |
| 金币 / 分数 | 右侧钱币 + 星星图标 |
| 目标 行 | 剪贴板图标 + `hud-goal` |
| 体温值 / 区域 / 潮湿 / 夜间危险 | 四个独立 chip（温度计/风/水滴/月亮图标），各占一格 |
| 右下斜纹警示条 | `drawHazardStripe()`，在环境行右端 |

数值、目标、环境全部走原有 `refreshStats()` / `refreshGoalHud()` / `refreshEnvironmentHud()`，
和键盘版共用同一套状态机，所以鼠标/键盘、HUD/面板之间的显示不可能对不上。
