## 与评分项对应的证据

### 可玩性（30）

- [x] 自动化证据：首层竖屏触控交互 4/4；桌面界面/启动回归 13/13；首五层真实上下楼、返家、睡觉旅程 1/1。
- [ ] 作者真人试玩：至少记录实际体验者、设备/浏览器、阻塞点、反馈和改动；目前仓库说明仍把“好不好玩”留给人工试玩判定。
- [ ] 公开部署后的新设备冒烟测试：从新会话开始，确认加载、输入、对话/搜刮、楼层切换、保存和继续。
- [ ] 手机范围说明：首层触控有 E2E；首五层完整旅程的 E2E 使用键盘；移动中旋转不动态重排；地图没有竖屏适配。不要宣传“完整手机通关已验证”。

### AI 运用（25）

- [x] 可核验的运行边界：公开默认 NPC 是离线、确定性的规则人格脑，不是生成式模型；行动建议经规则执行器校验。
- [x] 可核验的可选功能边界：代码提供需显式配置的本地 Ollama 路径；配置存在不等于公开版已连模型或本次录屏运行了模型。
- [ ] **开发期实际使用的 AI 工具记录：**【作者补充工具/模型/版本、日期、具体任务、输入输出或代码 diff、使用结果；没有则写未使用】。
- [ ] **若有现场生成式推理：**【实际模型名称/版本、运行位置、配置方式、一次可重现输入输出、时延/失败降级表现及截图/日志】。没有就不要声称。
- [ ] **Qoder / ModelScope API Inference / DGX Spark：**分别核实有无实际使用；逐项提供真实执行截图或运行日志。当前默认试玩不请求云模型 API；是否有可引用的历史本地推理实验须由作者核对原始记录与对应版本。
- [ ] **工具使用截图或记录：**保留原始界面截图、终端输出、任务/运行编号、日期与代码版本。游戏截图只能证明游戏画面，不足以证明用了某个 AI 工具或模型。

### 完成度（20）

- [x] 仓库状态：当前已验证可玩范围为第 1–5 层；项目代码/测试覆盖生存、探索、搜刮、背包、NPC 交易、宿舍制作、睡眠和本地存档。
- [x] 现有记录：`npm run typecheck` 通过；`npm run test` 为 58 个测试文件、762 项通过；构建通过；相关 E2E 结果见 [`B3-UI-07_MOBILE_PORTRAIT.md`](B3-UI-07_MOBILE_PORTRAIT.md)。构建有约 1.61 MB 主 JS 超过 500 KB 建议值的提示。
- [ ] 公开构建验证与失败恢复：在魔搭创空间按发布构建实际检查资源路径、刷新/重载、存档、桌面和目标手机。
- [ ] 范围表述：十万层设定是远期目标，不应称十万层内容/完整结局已经实现。

### 创意与呈现（15）

- [ ] 按 [`COMPETITION_DEMO_SCRIPT.md`](COMPETITION_DEMO_SCRIPT.md) 录制；明确显示当前首五层范围、默认 NPC 的规则驱动标签及任何剪辑跳切。
- [ ] 录屏分辨率、字幕、音量、横屏可读性和链接访问完成检查。
- [ ] 核实参赛作品首发时间、原创声明和是否参加过其他赛事；仓库本身不能证明比赛资格事实。

- [ ] 逐项补齐创作过程、作者与 AI 分工、一次真实问题与解决、经验、工具和素材来源。
- [ ] 只引用与本次投稿版本对应的证据；对历史实验说明日期、版本和与当前默认体验的差异。

## 作者必须核实或提供的内容

1. 作者姓名/署名、最终参赛方向，以及是否已按要求报名、公开发布构想。
2. 可实际访问的魔搭创空间试玩链接、演示视频链接；部署版本对应的 commit。
3. 本次开发/演示实际用过的 AI 工具与模型，逐项具体用途、日期/版本、真实截图或运行记录；明确区分**规则驱动 NPC**与**真实模型推理**。
4. 仓库 RFC 中记录的 2026-11-11 本地 Ollama/Spark 实验是否属于可引用的真实证据；需要原始记录、版本对应关系和复现确认。若无法核实，投稿中不将其作为实际使用证明。
5. `public/assets/`、`src/assets/`、`art-src/` 等素材逐项来源、作者、许可证/授权，及是否使用 AI 生成；检查音频、字体、图像和动画，不只检查本次移动端改动。
6. 真人试玩反馈、提交作品符合原创/首发与授权条件的确认，以及任何必要的隐私/署名决定。
7. 最新截止时间：ModelScope 官方活动页当前显示报名截止 **2026-12-01 10:00**；详细说明页所述报名时间与之有出入。请以魔搭报名/作品提交页面或主办方最新通知核实具体截止时刻，不要仅依赖本清单。
