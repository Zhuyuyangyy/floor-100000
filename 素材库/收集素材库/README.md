# 收集素材库

外面收集来的素材放这里：队友发来的包、网上下载的图、AI 生成的候选图。

这里既有待筛选原材料，也有已经按交付需求整理的首章候选素材。候选素材尚需在单独的游戏接入工作中使用和验证。

首章入口：[首章待用美术设定集](首章待用美术设定集/README.md)，其中按角色与楼层保存图片、动画、参考和说明。

## 流程

```
01-待筛选/  →  02-已采用/  →  美术设定集/  →  public/assets/
     ↓
  03-弃用/
```

| 目录 | 放什么 | 下一步 |
| --- | --- | --- |
| `01-待筛选/` | 刚收进来、还没看过的 | 看一遍，决定去 `02` 还是 `03` |
| `02-已采用/` | 决定要用的，但还没切、没接 | 切好规格后复制进 `美术设定集/` |
| `03-弃用/` | 看过但不用 | 放着或直接删 |
| [首章待用美术设定集/](首章待用美术设定集/README.md) | 整理后的首章角色与五层场景候选素材 | 在独立分支接入并验证 |

## 命名

`来源-内容-日期.png`，例：

```
队友-角色草图-1107.png
AI-货箱-1107.png
网图-废弃工厂-参考-1107.png
```

**来源必须写。** 因为授权状态要能追溯——三个月后没人记得这张图是哪来的。

## 一条不能越的线

**来源不明的图，只能当参考，不能进游戏。**

进 `public/assets/` 的素材必须是三种之一：

1. 自己画的 / 代码生成的
2. 许可证明确允许商用（如 CC0、CC-BY，且要记进 `THIRD_PARTY_NOTICES.md`）
3. 项目负责人明确授权提供的

`CLAUDE.md` 里有硬约束，`docs/reference/` 里那份《This War of Mine》拆解就是例子：机制可以参考，图一个像素都不能用。

## 体积

这个目录容易涨到几百 MB。**整包 zip、几十 MB 的原图不要提交进 git**，放 `re/incoming/`（已在 `.gitignore` 里）。

小图（几百 KB 以内、候选数量不多）可以提交，方便队友看。
