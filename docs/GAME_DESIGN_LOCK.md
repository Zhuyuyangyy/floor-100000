## 1. 核心定位

**《第100000层：末日宿舍》**是一款 2D 像素生存沙盒，结合**垂直阶级社会模拟**、资源管理、基地建设、人际关系与权力斗争。

一句话：**你从塔楼最底层的一张床醒来，一路向上攀爬，直到有机会决定整座塔楼的命运。**

这不是「宿舍版横版冒险」，也不是「模拟经营」。它是：

> **巨型塔楼探索 × 近景生存 × 宿舍基地建设 × 阶级与权力**

地图是承载这个故事的世界，生存是每天必须面对的现实，**阶级与权力才是推动长期游玩的动力**。

## 2. 不可擅自改变的规则

以下为硬规则，违反即视为设计回归：

1. **玩家初始位置为第 1 层**，不是第 100000 层。
2. **第 100000 层是塔楼顶端与长期目标**，不是出生点。
3. 塔楼总览、楼层群视图、具体楼层**属于同一个连续世界**，不是三款游戏。
4. **缩放探索用于观察、选择和规划，不等于无条件瞬间传送。** 实际移动必须满足楼梯、电梯、通行资格或其他已解锁条件。
5. 具体楼层保留角色移动、生存、搜集、制作、家具交互与基地建设。
6. 楼层身份、已探索状态与重要世界变化**必须持久化**。
7. 保持 Phaser + TypeScript + Electron 技术基线。
8. **不得为简化开发而删除阶层差异、向上攀升或社会关系的长期设计目标。**

## 3. 世界结构：六个阶层

楼层越高，资源、技术与财富总体越丰富；但门禁、安保、政治风险与利益冲突也逐级上升。

| # | 阶层 | 楼层区间 | 层数 | 环境与规则基调 |
|---|---|---|---:|---|
| 1 | 底层贫民区 | 1–99 | 99 | 玩家起点。废弃物资、简陋宿舍、漏水管道、黑暗走廊。基础食物与净水珍贵，靠拾荒、打零工、邻里交易求生 |
| 2 | 工人宿舍区 | 100–999 | 900 | 较稳定供水、工作岗位、基础商店；但工头、债务与配给制度控制普通人的生活。开始接触组织与阶层规则 |
| 3 | 工业与交易区 | 1000–9999 | 9,000 | 机械零件、能源设备、交易网络丰富。可经制作、贸易、任务积累财富；接触黑市与安保力量 |
| 4 | 中产与商业区 | 10000–49999 | 40,000 | 更好的住宅、医疗与商业设施。身份认证、许可证、债务记录与关系网决定可接触的资源 |
| 5 | 富人特权区 | 50000–89999 | 40,000 | 先进设备、稀有物资、私人服务。可获得权贵赏识，但面对更严格门禁、派系竞争与利益交换 |
| 6 | 统治核心 | 90000–100000 | 10,001 | 稀有科技、核心设施、政治秘密与最高权力。最终的忠诚考验、权力争夺，或改变塔楼命运的选择 |

- 上述区间为**首版设计基线**，具体分界可通过试玩调整。
- **不可改变的规律**：阶层逐级上升、资源越来越高级、社会规则越来越复杂、越往上越接近权力核心。
- 这些区间**不要求每层手工设计**：未探索区域用紧凑聚合状态 + 程序化模板 + 可复现种子按需生成；重要地点拥有独特内容。

## 4. 四条互相影响的成长路线

玩家成长不止等级与装备。以下四条线**必须能在架构上互相影响**（首版不必全部做深，但底层数据结构必须允许）：

| 路线 | 从 | 到 | 决定什么 |
|---|---|---|---|
| **生存能力** | 喝不上干净水 | 净水、食物储备、医疗、安全住所 | 能否承受更远更危险的探索 |
| **财富与产业** | 拾荒者 | 商人、工坊主、资源供应商 | 买装备、雇帮手、疏通关系；也成为他人目标 |
| **人脉与声望** | 无人认识 | 居民信任、完成委托、交换秘密 | 任务、交易与通行资格 |
| **权力与影响力** | 无足轻重 | 依附权贵 / 独立势力 / 联合底层 / 争夺统治 | 最终改变整座塔楼的规则 |

### 设计原则：同一物品的多重价值

一个物品可以同时具备**生存价值、经济价值与政治价值**。示例（设计意图，非已实现剧情）：

> 为获得一名富豪信任，你替他找到稀缺电池 → 他给你进入上层的通行证 → 你在上层发现这些电池本可改善底层供电 → 此时你可以继续为富豪工作、暗中把资源送回底层、或把秘密交给反抗组织。

**这是本作与普通生存游戏真正拉开差距的机制，任何简化都不应删除它。**

## 5. 基础循环

```
底层醒来 → 查看补给与状态 → 在塔楼总览/楼层群中规划路线
    → 满足通行条件下前往目标楼层
    → 探索 / 搜集 / 交易 / 制作 / 建立关系 / 规避风险
    → 返回宿舍 → 使用/制作/建设 → 睡觉过天
    → 新一天：资源更紧、关系变化、新的委托与风险
    → 重复，逐层向上，直至触及塔楼顶端
```

- 一昼夜需要至少数次有意义行动（拾取、交易、制作、建设、社交、睡觉）。
- **无软锁**：关键推进资源必须存在至少一条确定性获取路径。
- 死亡有可解释原因；失败后可重开。

## 6. 四条终局路线

终局由玩家**长期行为、关系与选择自然形成**，不是最后弹出四个按钮。

| 路线 | 形态 |
|---|---|
| **A 权贵代理人** | 为上层完成任务、获取信任与特权，成为权力体系内部的重要人物；可选择维持秩序、架空主人，或取而代之 |
| **B 独立商人与产业领袖** | 建立贸易网络、积累资本、控制关键资源；未必成为统治者，但让各方离不开你 |
| **C 底层起义** | 帮助工人组织起来，秘密运输物资、传播消息、争取关键人物，挑战不公平的配给与阶级制度 |
| **D 夺取统治权** | 利用财富、人脉、情报与派系矛盾争夺最高权力；取代原统治者，或建立新秩序 |

首版**不要求实现全部终局**，但架构必须允许它们成立。

## 7. 对旧 GDD（v0.1）的冲突裁定

`docs/01_GDD.md` 中以下设定**已被本文取代**，属早期原型假设，不再有效：

| 旧设定（v0.1） | 新裁定 |
|---|---|
| 玩家从第 100000 层的一张床开始 | **作废**。改为从第 1 层开始 |
| 第 100000 层 = 玩家宿舍 / 安全屋 | **作废**。第 100000 层 = 统治核心 / 长期目标 |
| 正式胜利 = 第 7 夜结束后到达第 8 天 06:00 且 HP > 0 | **作废**（作为最终胜利条件）。存活天数转为阶段性生存目标 |
| 首版只探索 100000–99996 五层 | **作废**。五层范围重映射为底层贫民区的起始可及范围 |
| 「熬过 7 天」为核心目标 | **降级**为早期生存压力，不再是终局 |

GDD 中仍然有效的部分：生存数值框架、15 种物品与制作配方、NPC 对话树结构、风险事件类型、非目标清单、像素美术与操作方案。

## 8. 非目标（延续 v0.1 并强化）

多人联机、排行榜、账户登录、商城付费、AI 自由聊天 NPC、3D、复杂物理、动作战斗、无限技能树、数百种材料、移动端虚拟摇杆、云存档、**十万层同时加载**、超长剧情、新手教学大系统。

**「AI 自由聊天 NPC」的边界（2026-11-11 ADR-001 修订）**：开放域自由聊天仍是非目标——模型不生成剧情、不扮演任意角色、不直接读写 `GameState`、不改数值、不绕过生存/经济/战斗规则。允许的是**规则校验内的决策 NPC**：模型只能从既有合法动作集中提出建议，建议必须经规则执行器校验后才生效，未通过校验一律丢弃；推理服务不可达时自动退回原选项树，玩法和无 AI 时一致。批准范围仅限 `feat/ai-npc-spark-integration` 分支内的 B6 先行实现，**合并回主分支前需重新确认**。条款依据见 `docs/plans/2026-11-11-ai-npc-spark-integration-rfc.md` §2–§4。

**新增非目标**：本轮不做完整社会模拟的全部系统；不为远端楼层模拟完整生活与物资变化。
