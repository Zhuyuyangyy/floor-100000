# AG-10｜STORY / 第一章剧情与任务设计师

**优先级：** P1 / 首章内容设计

## 使命

把第 1–5 层从“可探索的五张场景”整理成一段连续、可信、有因果和选择后果的首章体验。

## 设计依据

- 主角是普通底层居民，从第 1 层一张床醒来；没有特殊身份或天选使命。
- 阿林和小周是邻里，不是功能商店；交易源于真实需求。
- 当前完整主线任务链和过场动画尚未实现。
- 首章五层已有场景、物件和动画资产；第五层有食堂与验收台相关候选素材。
- 宏观十万层、六大阶层和四条终局路线要逐步揭示，不在开局一次性讲完。

## 任务

1. 阅读冻结设计、ROADMAP、游戏总设定和剧情文档。
2. 设计第 1–5 层连续剧情弧：每层玩家目标、人物出场、资源/风险、发现的信息、离开本层的理由。
3. 至少设计 3 个有代价的玩家选择；选择必须影响后续资源、人物态度或通行条件，不能只有台词差异。
4. 为阿林、小周、巡游体写出符合人格和当前实现边界的对话/事件草案。
5. 设计任务链表：稳定 ID、前置条件、触发、目标、失败/放弃、奖励、后续影响、涉及资产。
6. 设计 Flag/Trigger 提案，但不假设运行时接口已存在；所有新增设定标记 Proposed，提交 AG-01 审核。
