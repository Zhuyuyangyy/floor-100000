# 素材库

《第100000层：末日宿舍》的美术资料总入口。

```
素材库/
├── 美术设定集/          ← 美术与剧情设定
│   ├── 01-角色/
│   ├── 02-场景/
│   ├── 03-物品与家具/
│   ├── 04-界面/
│   ├── 05-特效/
│   ├── 06-待做参考/
│   └── 07-世界观与剧情/
└── 收集素材库/          ← 收集素材和首章候选素材
    ├── 首章待用美术设定集/  ← 首章角色、五层场景和动画素材
    ├── 01-待筛选/
    ├── 02-已采用/
    └── 03-弃用/
```

首章交付入口：[首章待用美术设定集](收集素材库/首章待用美术设定集/README.md)。这里包含角色、逐层场景、物件、动画和参考图，供后续分支接入游戏。

## 这个文件夹是什么

- **是**：给人看的设定集。打开就能翻，不用跑代码、不用找路径。
- **不是**：游戏运行时加载的目录。游戏读的是 `public/assets/`；下表中的旧版展示图多为运行素材的副本，首章待用素材则是独立交付文件。

修改旧版展示图时应同步对应原件；首章待用素材在其目录中维护，接入游戏后再按实际使用情况同步。

## 加东西的三条规则

1. **已完成的**：先改原件（`public/assets/` 或 `art-src/`），再覆盖本目录对应文件。只改这里不会影响游戏。
2. **准备做的**：放 `美术设定集/06-待做参考/`，文件名前面带上打算用在哪（例：`B4-区段总览-参考.png`）。
3. **别往这里放大文件**。整包 zip、几十 MB 的设计原图放 `re/incoming/`（已在 `.gitignore` 里，不进仓库）。

## 收集来的素材放哪

放 `收集素材库/01-待筛选/`，命名带来源和日期（`队友-角色草图-1107.png`）。看完之后去 `02-已采用/` 或 `03-弃用/`。

**来源不明的图只能当参考，不能进游戏**——详细规则写在 `收集素材库/README.md`。

第三方素材的来源与许可证记在仓库根目录 `THIRD_PARTY_NOTICES.md`：目前只有 Kenney 的 CC0 选择箭头是外部素材，`artpack/` 整包由项目负责人提供，其余全部程序化生成或代码绘制。

## 已知缺口

- 第 5 层以上的环境美术**完全没有**（B4/B9 才做）。
- **怪物没有形象**：战斗里只有名字和血条，没有立绘或精灵。
- NPC 只有 3 个（阿林、小周、流浪者），委托、商人、守卫等角色都还没有脸。
- **没有音频素材文件**：所有音效是运行时用 Web Audio 现场合成的，改音效是改代码参数，不是换文件。
