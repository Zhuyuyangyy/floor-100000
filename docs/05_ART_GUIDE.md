# ART GUIDE — 统一像素风视觉规范

## 1. 风格定位

“末日压抑的大楼 + 暖色灯光的小宿舍”，不做儿童卡通。重点表现大量宿舍窗格、上下无限延伸的楼体背景、走廊门牌、杂物和低光照，画面始终保持交互可读。

## 2. 规范

- 横版 16:9，内部渲染分辨率 640x360，整数倍缩放；禁用平滑滤镜。
- tile 16x16 px；人物占位 16x24 px；家具有 16/32 的模数；NPC 朝向用同一骨架。
- UI 使用深色半透明背景 + 高对比白字，重要资源/交互提示清楚，禁止小到无法辨识的字号。
- 配色建议：楼体深蓝灰 `#18242C`、墙体灰 `#354650`、灯光橙 `#F4B66A`、危险红 `#E56D63`、安全青 `#77C6A4`、文字米白 `#ECE8D8`。
- 先程序化占位：床、门、储物柜、角色、楼梯、容器用 Canvas/Graphics 绘制 8-16 色像素图形；别在美术交付前阻塞主循环。
- 动画节制：玩家待机/走路 2-4 帧就够；日夜以光照/背景变化传达，避免模糊特效毁掉像素感。

## 3. 场景辨识度

楼层号在 B2 已重映射为向上增长（见 `docs/B2_TOWER_ARCHITECTURE.md` §5），玩家从第 1 层贫民区出发。五层各有独立身份，实现见 `src/render/corridors.ts`：

| 层 | 名称 | 视觉身份 | 关键道具 |
|---|---|---|---|
| 1 | 玩家宿舍 | 暖光、安全、家的感觉 | 窗格透光、壁灯光池、床、工作台、门、管道、墙上告示 |
| 2 | 邻居宿舍 | 有人居住的拥挤 | 每间一门、门牌、擦鞋垫、晾衣绳、门口鞋 |
| 3 | 废弃储物层 | 最暗、无人打理 | 货架、货箱堆叠、倾倒的箱、墙角蛛网、地面灰尘 |
| 4 | 维修层 | 结构外露、机械感 | 双层水平管道、竖向管与阀轮、电箱、水箱、踢脚线导管、警示条纹、墙面模板字 |
| 5 | 废弃食堂 | 最暖、为人群而建 | 一排吊灯、整面后墙货架、长柜台与取餐槽、托盘水壶、长凳、菜单板 |

**共同基底**：五层共用同一套 `tile_wall` / `tile_floor` 贴图与「天花阴影 + 踢脚线」两条带，整栋楼读起来是同一建筑物；差异只来自每层的淡色罩调与道具。罩调必须轻——墙砖本身已是暗值，重罩会把道具压进背景，房间就不再可读（阶级差别要靠**房间里有什么**，而不是**看得见多少**）。

**确定性**：房间装扮用 `variant(floor, room, n)` 取变体，不用 `Math.random()`——装扮是世界状态，重复访问与场景重启必须一致。

**验证**：`e2e/art.spec.ts` 每次运行重新生成五层截图（`30`–`34-floor-*.png`），美术回归体现为截图差异而非「上周看着还行」。

## 4. 法务与素材

全部原创、授权或明确许可素材。不要复刻某位视频作者的标志性角色/完整楼体画面；禁止直接抓取网络图片当“临时资源”提交。音效也应采用有明确许可的来源或自制简单提示音。

## 5. 未来美术交付清单（P0 玩法实现后）

玩家立绘与行走动画、2 名 NPC、5 种房间模块图块、道具小图标、床/门/窗/制作台、停电暗色覆盖、短 UI 点击音与广播音。先统一图块尺寸、色板和图层命名，再批量生成/绘制。
