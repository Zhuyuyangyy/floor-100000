# ROADMAP —《第100000层：末日宿舍》B2 → B10

最高设计权威：[`GAME_DESIGN_LOCK.md`](GAME_DESIGN_LOCK.md)。
本路线图只安排顺序、交付物与验收标准，**不得**修改设计冻结文档中的任何核心设计。
技术基线：[`02_TECH_SPEC.md`](02_TECH_SPEC.md)。

## 路线总览

| 阶段 | 名称 | 一句话目标 |
|---|---|---|
| B2 | 塔楼世界与导航 | 世界结构成立：从第 1 层开始，十万层可查看、可规划、不可乱传 |
| B3 | 首个完整生存章节 | 第 1–5 层能独立玩完一段完整生存循环 |
| B4 | 十万层世界生成 | 100 个区段可复现、按需生成、性能可控 |
| B5 | 资源经济与基地建设 | 同一物资同时具备生存价值与经济价值 |
| B6 | NPC 与关系网络 | 居民有身份、需求和记忆，玩家行为改变关系 |
| B7 | 阶级、势力与权力 | 资源 + 人脉共同决定社会地位与上升通道 |
| B8 | 多路线终局 | 四种路线由长期行为自然决定，而非只换结局文字 |
| B9 | 世界内容与表现力 | 六大阶层一眼可辨，探索不再是重复走廊 |
| B10 | 平衡、性能与发行 | 稳定、完整、可安装、可持续游玩 |

> B9 的美术工作可以提前逐步开展，但不得挤占 B2、B3 的核心功能开发时间。

## B2 · 塔楼世界与导航 ✅ 本轮已完成

### 目标与玩家价值
把「第 100000 层」从一个静态 Demo 房间变成一座**结构真实**的塔：玩家从第 1 层贫民区醒来，可以查看整座塔、查看任一区段、查看任一楼层详情，并只能通过实际打通的通路进入已解锁的楼层。

### 前置依赖
- 设计冻结文档（`GAME_DESIGN_LOCK.md`）
- 既有五层模板、生存系统、存档系统

### 交付物
- `src/core/tower.ts` — `TowerModel`：100000 层的纯函数聚合视图（不按层存对象）
- `src/systems/TowerNav.ts` — 三层导航的纯状态机（总览 / 区段 / 楼层）
- `src/scenes/TowerOverviewScene.ts` — 渲染与输入，滚轮缩放、拖动平移、点击与键盘均可操作
- `src/core/devMode.ts` — `?devfloor=` / `?devwin=` 开发专用夹具开关
- 起始层重映射：五层模板 100000→1、99999→2、99998→3、99997→4、99996→5
- 第 8 天自动胜利从生产逻辑移除（保留 `?devwin=1` 夹具）
- HUD / 帮助文本 / 新游戏目标提示改为「从第 1 层爬到第 100000 层」
- `e2e/tower.spec.ts`、`src/tests/towerNav.test.ts`、`src/tests/devMode.test.ts`

### 验收标准
- [x] 新游戏从第 1 层开始；第 100000 层仍是合法逻辑楼层与未来终点，但不再是出生点
- [x] 三层导航完整可用：总览 → 区段 → 楼层详情，ESC 逐级返回
- [x] 当前楼层 / 当前区段始终高亮，打开地图即定位到玩家所在区段
- [x] **地图选中不等于传送**：只有 `canEnter()` 通过的楼层才能进入
- [x] 返回地图后玩家位置、生命、物资、时间、探索状态不丢失
- [x] 旧单测与 E2E 全部通过

### 自动化测试
- `src/tests/tower.test.ts`（17）阶层边界 / 区段划分 / 楼层记录 / 通行判定
- `src/tests/towerNav.test.ts`（29）层级切换 / 坐标拾取 / 缩放滚动钳制 / 键盘光标 / 进入许可
- `src/tests/devMode.test.ts`（6）开发夹具解析与拒绝非法值
- `e2e/tower.spec.ts`（9）真实浏览器导航、高亮、禁传送、状态保留、开发夹具

### 不在本阶段实现
程序化楼层生成、社交模拟数据、经济、NPC 关系、终局系统、美术定型。

### 进入 B3 的准入条件
B2 全部验收标准通过 + 全量回归（typecheck / 单测 / E2E / 生产构建）通过 + 人工验收。

## B3 · 首个完整生存章节

### 目标与玩家价值
新玩家能在第 1–5 层**独立玩完一段完整的生存流程**：探索 → 搜集 → 消耗 → 回宿舍 → 制作 → 睡觉 → 存档 → 继续探索。这一阶段验证「好不好玩」，而不是「世界有多大」。

### 前置依赖
B2 的世界结构与导航。

### 交付物
- 打通第 1–5 层的完整游玩闭环，修复断裂环节而非重造轮子
- 明确的新手引导与目标提示（首日目标、如何上楼、如何获得水与食物）
- 死亡 / 继续 / 读档的完整体验
- 生存难度调参的可配置化（`config/game-balance.json`）

### 验收标准
- 新玩家无需说明即可完成：移动、搜刮、喝水、吃饭、制作、睡觉、上楼
- 一段完整循环内不会出现死档、白屏、状态丢失
- 有明确的失败反馈与可恢复路径

### 自动化测试
- 新增「完整生存循环」E2E：从第 1 层起床到第 5 层探索并返回宿舍入睡
- 生存模拟单测扩展：覆盖多日循环与资源耗尽路径

### 不在本阶段实现
第 5 层以上的内容、经济系统、NPC 关系深化、终局。

### 进入 B4 的准入条件
完整生存循环 E2E 通过 + 人工试玩确认「可玩」。

---

## B4 · 十万层世界生成

### 目标与玩家价值
把 B2 的聚合视图变成**可生成、可探索、可复现**的真实世界：100 个区段各自成体系，底层贫困、上层富饶的世界梯度成立。

### 前置依赖
B3 的生存循环（生成的内容必须服务于玩法）。

### 交付物
- 100 个区段的程序化楼层生成器（种子可复现）
- 按需生成 + 探索记录（不为 10 万层预分配对象）
- 各区段资源分布与危险度曲线
- 区段间通行条件（钥匙、权限、体力、通路）

### 验收标准
- 同一世界种子重复生成结果一致；不同种子有差异但难度曲线一致
- 跨区段生成不产生可感知卡顿
- 已探索楼层在返回时内容不变

### 自动化测试
- 生成确定性单测（同种子同结果、跨区段一致性）
- 性能基准测试（生成 N 个楼层的时间 / 内存上限）

### 不在本阶段实现
基地建设、NPC、派系、终局。

### 进入 B5 的准入条件
生成确定性与性能基准通过 + 梯度曲线人工确认。

---

## B5 · 资源经济与基地建设

### 目标与玩家价值
同一件物资既有**生存价值**（喝掉、用掉），也有**经济价值**（卖掉、换通行、换人情），玩家开始在「活下去」和「活得更好」之间做选择。

### 前置依赖
B4 的世界生成。

### 交付物
- 扩展的物资稀缺度与制作链
- 净水、电力、储存系统
- 宿舍升级（床、工作台、储水、防御）
- 交易与资源价格

### 验收标准
- 资源获取 → 消耗 → 制作 → 升级形成可持续循环，不会无限通胀或彻底枯竭
- 同一物品的三重价值（生存 / 经济 / 政治）在 UI 上可读

### 自动化测试
- 经济平衡模拟（多日资源曲线）
- 制作链完整性单测（每条配方可达）

### 不在本阶段实现
NPC 关系网络、派系、终局。

### 进入 B6 的准入条件
经济模拟收敛 + 人工确认循环可持续。

---

## B6 · NPC 与关系网络

### 目标与玩家价值
居民不再是对话树：他们有身份、需求和记忆，玩家的行为会真实改变他们对玩家的态度，从而影响资源、任务和通行机会。

### 前置依赖
B5 的经济系统（NPC 需求需要挂钩到物资）。

### 交付物
- 有身份、需求、关系和记忆的居民模型
- 委托、交易、好感、承诺与背叛
- 玩家行为 → NPC 态度的因果链

### 验收标准
- 同一玩家行为在不同关系下产生不同结果
- 关系能实际影响资源获取、任务解锁和通行许可

### 自动化测试
- 关系状态机单测（含背叛与修复路径）
- NPC 记忆持久化（跨存档）测试

### 不在本阶段实现
派系与权力体系、终局。

### 进入 B7 的准入条件
关系影响资源的链路测试通过。

---

## B7 · 阶级、势力与权力

### 目标与玩家价值
向上爬不再只是「打通楼层」：身份门槛、债务、许可证、上层赏识、派系、工人组织、黑市与情报共同决定玩家能走多远。

### 前置依赖
B6 的 NPC 关系网络。

### 交付物
- 身份门槛与许可证系统
- 债务与欠款机制
- 派系（上层 / 工人组织 / 黑市）与情报
- 社会地位的量化与可见反馈

### 验收标准
- 玩家能通过不同策略（钱、人脉、情报、暴力）获得向上机会
- 社会地位变化在游戏内有明确可见的反馈

### 自动化测试
- 势力关系与声望计算单测
- 许可证 / 债务边界测试

### 不在本阶段实现
终局分支实现。

### 进入 B8 的准入条件
至少三条互不相同的上升路径可跑通。

---

## B8 · 多路线终局

### 目标与玩家价值
终局由玩家的长期行为、资源、关系和世界状态**自然决定**，而不是在最后一章选一个选项。

### 前置依赖
B7 的阶级与权力体系。

### 交付物
- 四条路线：权贵代理人 / 独立商人 / 底层起义 / 夺取统治权
- 终局判定基于累积行为而非单次选择
- 每条路线的独特世界结果

### 验收标准
- 不同发展方式产生**不同的世界结果**，而非只更换结局文字
- 同一存档的终局可被复盘解释（为什么走到这里）

### 自动化测试
- 四条路线的终局判定模拟测试
- 终局不歧义（不会同时满足两条互斥路线）

### 不在本阶段实现
新内容扩展、平衡微调、发行准备。

### 进入 B9 的准入条件
四条路线判定互斥且可复盘。

---

## B9 · 世界内容与表现力

### 目标与玩家价值
六大阶层一眼可辨；探索不再是重复走廊。把现有像素资产体系扩展成统一的视觉语言。

### 前置依赖
B4 的世界生成（内容需要挂到区段上）。

### 交付物
- 六大阶层的环境、美术、音效
- 独特地点、人物故事、动态灾难
- 统一视觉语言规范（`docs/05_ART_GUIDE.md` 扩展）

### 验收标准
- 不同区域一眼可辨
- 探索有节奏变化，不再是同一走廊铺砖

### 自动化测试
- 资产完整性检查（每个区段类型有对应美术）
- 视觉回归截图基线

### 不在本阶段实现
平衡微调、发行准备。

### 进入 B10 的准入条件
六大阶层视觉可辨 + 人工确认探索节奏。

---

## B10 · 平衡、性能与发行

### 目标与玩家价值
游戏稳定、流程完整、可安装、可持续游玩。

### 前置依赖
B2–B9 全部完成。

### 交付物
- 生存难度与资源曲线调平
- 存档兼容与异常恢复
- 长时间运行性能（内存、帧率）
- 桌面安装包
- 真实玩家试玩与发行准备

### 验收标准
- 长时间运行无内存泄漏、无帧率劣化
- 坏档可恢复，不白屏
- 可安装、可启动、可退出

### 自动化测试
- 长时运行 soak 测试
- 存档兼容矩阵测试
- 安装包冒烟测试

### 不在本阶段实现
新玩法扩展。

### 发行准入条件
全部验收标准通过 + 真实玩家试玩反馈处理完毕。
