# 角色

四个可操作角色。动画不是逐帧手绘，是代码骨架（rig）驱动的：`art-src/rigs/*.rig.svg` 定义骨骼配色，`*.anim.json` 定义关键帧，由 `tools/assemble-rig-sheet.py` 装配成精灵表。

所以想改动作，改 JSON 数值再重新生成，不用重画。

## 每个角色的文件

每个目录 11 个文件，命名规律一致：

| 文件 | 用途 |
| --- | --- |
| `*_contact_sheet.png` | 接触表：7 段动画的所有帧排在一张图上，看造型用 |
| `*_idle_still.png` | 静止姿态的单帧放大图，看配色和轮廓用 |
| `all-actions.gif` | 7 段动画连播，看整体节奏 |
| `walk.gif` | 行走循环 |
| `idle.gif` | 待机 |
| `attack.gif` | 攻击 |
| `hurt.gif` | 受击 |
| `search.gif` | 搜刮 |
| `pickup.gif` | 拾取 |
| `die.gif` | 死亡 |
| `player.png` / `npc_*.png` | 游戏内实际使用的贴图 |

## 四个角色

| 角色 | 识别特征 |
| --- | --- |
| **幸存者** | 青绿连帽衫，大帆布背包（铺盖卷 + 压缩带）。玩家默认角色 |
| **阿林** | 宽肩、灰白短须、钢蓝背带裤，腰上挂着扳手 |
| **小周** | 约十二岁：头大身窄，琥珀色大外套长过臀 |
| **流浪者** | 夜里追你的东西：尖顶兜帽、没有脸、窄身长手长腿，5 色暗红黑 |

## 尺寸

角色精灵 64×96，场景瓦片 16px，家具 56px。`src/tests/sceneScale.test.ts` 里有 9 条比例不变量守着，改尺寸会让测试失败。
